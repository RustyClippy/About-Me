### 🧑‍💻 About Me

<p align="justify">  
  I'm <strong>RustyLucas</strong> — a student software engineer passionate about building robust, user-centric applications. My journey started with a simple question: <em>how do the apps I use every day actually work?</em> That curiosity turned into a habit of building things, breaking them, and refining them into production-ready solutions.  
</p>  

<p align="justify">  
  I started with the foundations of the web — <strong>HTML</strong>, <strong>CSS</strong>, and <strong>JavaScript</strong> — and I'm currently expanding into <strong>Python</strong>, <strong>AI</strong>, and <strong>Machine Learning</strong>. My approach is <strong>product-first</strong>: before writing any code, I ask <em>does this actually solve a real problem for a real user?</em> I study architecture and best practices early, ensuring I scale on strong foundations rather than technical debt. I write comprehensive documentation because I believe communication is as important as code.
</p>
