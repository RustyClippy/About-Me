My journey started with a simple question: <em>how do the apps I use every day actually work?</em> That curiosity turned into a habit of building things, breaking them, and refining them into production-ready solutions.  
</p>  

<p align="justify">

Every repository on my profile is a checkpoint of intentional engineering decisions, not just a functional output. I learn in public, mistakes included.  
</p>  

<p align="justify">  
  My approach is <strong>product-first</strong>: before writing any code, I ask <em>does this actually solve a real problem for a real user?</em> I study <strong>architecture</strong> and <strong>best practices</strong> early, ensuring I scale on strong foundations rather than technical debt.  
</p>
