### 🧑‍💻 About Me

I'm **RustyLucas** — a student software engineer passionate about building robust, user-centric applications. My journey started with a simple question: *how do the apps I use every day actually work?* That curiosity turned into a habit of building things, breaking them, and refining them into production-ready solutions.  

I started with the foundations of the web — **HTML**, **CSS**, and **JavaScript** — and I'm currently expanding into **Python**, **AI**, and **Machine Learning**. My approach is **product-first**: before writing any code, I ask *does this actually solve a real problem for a real user?* I study architecture and best practices early, ensuring I scale on strong foundations rather than technical debt. I write comprehensive documentation because I believe communication is as important as code.
