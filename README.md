<summary><h3>📎 Termux-AI — AI in your terminal</h3></summary>

A lightweight terminal-based AI assistant for the Termux environment, designed to make AI feel native in command-line workflows.

**Core ideas:**
- 💬 Chat with an AI assistant directly from the terminal
- 💻 Generate and explain code snippets
- 🐛 Debug scripts and fix common errors
- 📝 Summarize and transform text quickly
- ⚙️ Assist with daily terminal tasks and productivity
